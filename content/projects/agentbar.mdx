## What it is

AgentBar watches your terminal coding agents — **Claude Code** and **GitHub Copilot CLI** —
and notifies you when one of them needs something. A multiple-choice question, a permission
prompt, or a session that has gone idle waiting for input: AgentBar surfaces it in the menu
bar and brings the right terminal window back to the front so you can answer there.

## A notification tool, not an input tool

This is the constraint the whole app is built around. AgentBar never blocks your session
and never sits between you and the agent. Every prompt is still answered in your terminal,
where it was always going to be answered.

The hooks are fire-and-forget: the local server acknowledges immediately, so the hook
returns at once and your session never waits on the UI. And the contract is **fail-open** —
if the app is missing, unreachable, or errors in any way, the hook exits cleanly with no
output, exactly as if AgentBar were never installed.

## How it hooks in

The Claude Code plugin registers hooks across the interaction points that matter: turn
starts, questions, permission requests and denials, MCP elicitations, tool completions and
failures, idle notifications, and the task-finished / subagent-finished / session-ended
events.

When one fires, a bundled hook script POSTs the payload to AgentBar's local HTTP server —
`127.0.0.1`, an ephemeral port, and a per-launch bearer token — launching the app first if
it is not already running. AgentBar queues the item, badges the menu bar icon, and posts a
notification.

The nice part is what happens next: once you answer in the terminal, AgentBar notices the
session move past the prompt and **clears the item automatically**, whether you allowed or
denied. Nothing to dismiss.

## Installing

The app ships as a Homebrew cask and the Claude Code half as a marketplace plugin, whose
hooks activate on install with no `settings.json` editing:

```
brew tap jreed91/agentbar https://github.com/jreed91/agentbar
brew install --cask agentbar
```

```
/plugin marketplace add jreed91/agentbar
/plugin install agentbar@agentbar
```

Copilot CLI loads personal hooks from JSON in its config directory rather than from a
marketplace, so it is a one-time `make install-copilot` instead of a plugin install.
